# Specification

## Summary
**Goal:** Build a responsive, minimalist black-and-white marketing website for the men’s fashion brand “Column and Case” with core pages/sections (Home, Collection, About, Contact) and on-page brand/product imagery served from local static assets.

**Planned changes:**
- Create a clean black/white/gray visual theme (typography, spacing, borders, buttons/inputs, hover states) used consistently across the site.
- Implement top navigation with Home, Collection, About, Contact, including a mobile-friendly menu and current section/page indication.
- Build Home layout featuring the “Column and Case” name prominently plus a hero area using a static hero image.
- Add a Collection section/page with a responsive product grid (at least 8 items), each card showing a local placeholder image, product name, and price.
- Add an About section/page with short, restrained English editorial copy referencing “Column and Case”.
- Add a Contact section/page with a simple form (name, email, message) that shows an on-screen confirmation on submit, plus a clean footer with brand name and at least 2 links.
- Add and reference generated static images from `frontend/public/assets/generated` (logo/wordmark, hero, and product placeholders) with no backend image fetching.

**User-visible outcome:** Users can browse a modern black-and-white “Column and Case” site, navigate between Home/Collection/About/Contact on mobile or desktop, view a minimal product grid with images/prices, read brand copy, and submit a contact form to see an on-screen confirmation.
